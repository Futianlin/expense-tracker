# 支出记账（离线 PWA）

个人支出记账 app。数据只存本机浏览器（IndexedDB），不联网、不调用任何接口、不上传。

## 文件

- `index.html` —— app 本体（全部样式与逻辑内联，单文件可用）
- `manifest.webmanifest` / `sw.js` / `icon-*.png` —— 离线安装所需，**必须与 index.html 放同一目录一起部署**
- `DeepSeek识别约束.md` —— 给小票识别用的提示词模板（app「导入」页也有「复制识别提示词」按钮）

## 部署到 iPhone（免费、无需域名）

任选一个免费静态托管，把**整个文件夹**原样传上去（这几个文件缺一不可）：

1. **Cloudflare Pages**（推荐，无需装 git）：登录 dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets → 把本文件夹拖进去 → 部署完得到 `xxx.pages.dev` 链接。
2. **GitHub Pages**：新建仓库上传本文件夹 → Settings → Pages → 选分支 → 得到 `用户名.github.io/仓库名` 链接。

## 在 iPhone 上安装

1. 用 **Safari** 打开上面得到的链接（不要用微信/其他浏览器内打开）。
2. 点底部「分享」→「添加到主屏幕」→ 添加。
3. 主屏幕出现「记账」图标，点开即全屏像 App 一样使用；首次打开后**完全离线可用**。

## 使用闭环

- **AI 识别小票**：DeepSeek 识别小票 → 复制返回的 JSON → app「导入」页粘贴 → 解析 → 核对 → 确认入库（按一张小票 = 一笔支出记，金额=实付总价）。
- **手动记账**：明细页右下角「＋」新增，支持增删改查、类别、备注。
- **账单与可视化**：统计页可切「本月」（类别环形图）与「年账单」（12 个月柱状图）。
- **备份**：设置页定期「导出备份（JSON）」；换机/清浏览器前务必导出。

## 提醒

- 数据存于该浏览器，换浏览器或清缓存前先导出 JSON 备份。
- iOS 主屏幕图标（icon-180.png）为独立文件，属正常用法。
