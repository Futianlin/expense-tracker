# 天天记账 DayTally（离线 PWA）

完全离线的个人记账 App：**不联网、不调 AI 接口、数据只存本机浏览器（IndexedDB）**。在 iPhone / 安卓主屏幕像普通 App 一样全屏使用，首次在线加载一次后即可离线运行。

线上地址（GitHub Pages）：<https://futianlin.github.io/expense-tracker/>

## 功能

- **明细**：流水列表，可按日期或金额升 / 降序排序；支持按备注 / 类别 / 商品名搜索（跨所有月份）。
- **手动记账**：点「＋」记一笔，可记**支出**或**入账（收入）**；金额、日期（点日期直接弹日历）、类别（下拉可选）、备注。
- **购买明细**：AI 识别的小票自带商品明细（原文名 + 中文名 + 数量 + 单价 + 金额）；详情里可**编辑明细**——改数量 / 单价，金额自动用计算器重算并同步总金额。
- **AI 识别导入**：导入页一键**复制识别提示词**（或批量版）→ 连同小票 / 购物截图 / 银行消费记录发给 DeepSeek → 返回 JSON → 粘贴 → 解析 → 核对 → 确认入库。批量识别支持多张凭证按各自日期分别入库。
- **统计**：本月**环形占比图**（点扇区看该类别明细）、**年账单**（12 个月柱状 + 年度预算进度）、**趋势**（12 个月折线 + 月均线 + 该账本**月度预算红线**）。不同货币（账本）各自统计，不混算。
- **预算（按账本）**：每个币种可各自设**月度预算**与**年度预算**；月度用于趋势图红线与本月超支提示，年度用于年账单超支提示；输入即生效。
- **类别**：15 个内置类别（衣食住行、电话费、订阅等，带图标与颜色），可新增 / 改名 / 删除 / 编辑（改图标 / 改颜色，编辑与新增都是悬浮窗）；颜色会同步到统计图。
- **设置**：今日看板（可点某天看**分币种的金额与笔数**、日历里每天标注各币种**金额**、点日期可跳转）、预算（按账本月/年）、**语言（中文 / English，界面与识别提示词都会切换）**、导出备份。
- **每月定时记账**：设定「每月某日几点几分自动记一笔」，如每月 1 日 08:00 房租、15 日订阅费。可选**本月开始**（已过的日期会补记本月）或**下月开始**。到设定时刻会自动记一笔；若当天没打开 App，下次打开会自动补记漏掉的月份。支持支出 / 入账、金额 + 币种、类别、备注。
- **货币（每笔自带 = 不同账本）**：不在设置里统一货币；记账时每笔可选一种货币（EUR / USD / GBP / CNY / JPY / HKD / SGD / AUD / CAD / CHF / KRW / SEK / DKK / NOK / NZD / INR），列表与详情按各自符号显示。**统计页与明细页顶部的「账本」栏**可切换查看某一种货币的统计/明细，互不混算（离线、无汇率换算）。记账弹窗的货币下拉按你记录得最多的币种排在前面。
- **导出 / 备份**：导出完整 JSON 备份（含类型、类别）或 CSV 明细（Excel / Numbers 可开）；支持从文件恢复。

## 部署（免费、无需域名）

把**整个文件夹**原样上传到任一免费静态托管（这几个文件缺一不可）：

1. **GitHub Pages**：新建仓库上传本文件夹 → Settings → Pages → Source 选分支 → 得到 `用户名.github.io/仓库名` 链接。
2. **Cloudflare Pages**：登录 dash.cloudflare.com → Workers & Pages → Create → Upload assets → 拖入本文件夹 → 得到 `xxx.pages.dev` 链接。

## 安装到主屏幕

**iPhone / iPad（Safari）**：用 Safari 打开网址 → 点底部「分享」→「添加到主屏幕」→ 命名（如“天天记账”）→ 添加。主屏幕出现图标即完成。

**安卓（三星 / 华为 / 小米 / vivo，Chrome 或自带浏览器）**：用浏览器打开网址 → 点右上角「⋮」菜单 →「添加到主屏幕 / 安装应用 / 添加到桌面」→ 确认；出现“安装应用”横幅时直接点它更快。

详细分品牌教程在 App 内「设置 → 用户手册」（支持导出 PDF 打印）。

## 数据与隐私

- 数据保存在本机 IndexedDB（库名 `expense-db`），**不联网、不上传、不调用任何接口**。
- iOS 可在「设置 → Safari → 高级 → 网站数据」查看 / 清除。
- 换手机或清缓存前，先在「设置」导出 JSON 备份，之后用「从文件恢复」导入。
